# Backlog Demo — Pricing Master Simplified 2026

Target: **satu paket memiliki satu contoh visual yang unik dan benar-benar menunjukkan capability utamanya**.

Status:

- **Sumber tersedia** — project nyata sudah ada; pilih screenshot yang paling relevan.
- **Perlu akses internal** — perlu akun demo/staging untuk menampilkan dashboard atau workflow.
- **Perlu demo baru** — belum ada project yang cukup representatif.

Sebuah demo dianggap selesai setelah memiliki screenshot hero 16:9, satu capability pembeda, caption, URL bila live, dan data dummy yang aman.
